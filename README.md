# 指标口径与分析实验平台

面向业务指标定义、口径管理、聚合查询、分群分析、A/B实验设计、分析方案管理与数据服务发布的数据分析工程平台。

这是一个前后端分离的管理平台：前端 Vue 3 + Vite + TypeScript，后端 FastAPI（Python）。
两边各自独立启动，前端 dev server 已关掉自动打开页面，启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/              统一请求封装
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false）
├── backend/                  FastAPI（Python） 后端
│   ├── app/routers/          每个业务模块一组接口
│   ├── app/services/         业务规则与状态流转
│   └── app/store.py          内存数据仓库与示例数据
├── .gitignore
└── docker-compose.yml
```

## 启动

### 后端

```bash
cd backend
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
./run.sh
```

健康检查：`curl http://127.0.0.1:8000/api/health`

### 前端

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，
需要自己访问。`/api` 由 vite 代理到后端 `http://127.0.0.1:8000`。

## 聚合查询下钻：模板级快照

聚合查询模板与下钻路径围绕同一个模板版本共同变化：

1. **提交模板验证**：固化维度字段、度量字段和「允许的下钻层级」（等于维度个数），
   为每一层生成确定性聚合结果与层摘要，并计算整个快照的摘要校验值。新版本先停在
   `待启用`，已启用模板的旧版本继续对外服务。
2. **启用模板**：核对同版本快照与缓存摘要后，把该版本切成当前版本；旧版本快照和旧缓存
   转为 `历史`，绑定旧版本的路径同步转历史并保留层级结果。
3. **启用路径**：路径必须与模板当前快照的维度逐层一致、中间层级完整、逐层缓存摘要一致，
   启用后只读取同一模板版本的快照与缓存。
4. **按层级展开**：`GET /api/datadrill/{id}/levels?level=N` 返回每一层的实际维度、度量、
   行数、汇总、聚合结果与层摘要。缺少中间层级、模板已废弃/换版、缓存摘要不一致时返回
   409 并带上结构化原因，`保留上一层结果` 保持上一次成功展开的层级（换版场景回放旧版本历史结果）。
5. **查询影响记录**：`GET /api/queryboard/audit` 可按模板编号/版本/路径/动作核对提交验证、
   启用、展开与拒绝流水；这些内部表（`_query_snapshots`、`_query_cache`、`_drill_bindings`、
   `_query_audit`）不进入运营概览。

样例：`QUER-0002` 使用「日期、渠道」两个维度，`DATA-0002` 默认展开到第二层。提交模板验证并
启用后，两层分别显示各自的度量（`支付金额` / `下单用户数`）与聚合摘要。

### 权限

请求头 `X-Operator`、`X-Role`（`管理员` / `编辑` / `只读`，也接受 admin/editor/viewer）
决定业务归属校验：

- 管理员可修改全部记录；
- 编辑只能修改自己名下的记录，他人或共享模板/路径的修改会被拒绝；
- 只读角色只能查看，不能创建或改动任何记录。

前端顶栏可以切换值班人和角色，请求封装会自动带上并做百分号编码。

## 约定

- 每个模块的前端页面在 `frontend/src/views/<模块>/index.vue`，后端接口在
  `backend/app/routers/<模块>.py`，业务规则在 `backend/app/services/<模块>.py`。
- 列表接口统一返回 `{ items, total, page, size }`，动作接口统一返回 `{ ok, message }`。
- 状态流转只允许在 `app/services` 里改，路由层不做业务判断。
- 聚合查询下钻链路的端到端校验：`cd backend && .venv/bin/python tests/check_query_drill.py`。
